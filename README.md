# Exercícios de Python

Repositório com meus estudos e minha evolução em Python. Aqui resolvo pequenos problemas do dia a dia, ligados a hábitos e finanças pessoais.

Atualizo sempre que concluo um novo exercício, com meta semanal.

## Exercícios

| # | Exercício | O que faz | Conceitos |
|---|---|---|---|
| 1 | [ex001_orcamento_diario.py](ex001_orcamento_diario.py) | Calcula o excesso ou a sobra do orçamento diário. | `if`, `input`, `print` |
| 2 | [ex002_revisao_semana.py](ex002_revisao_semana.py) | Faz a revisão dos gastos da semana e apresenta um resumo. | `for`, listas |
| 3 | [ex003_rastreador_habitos.py](ex003_rastreador_habitos.py) | Calcula o aproveitamento dos hábitos diários durante a semana. | `for`, maior valor, dicionários |
| 4 | [ex004_calculadora_reserva_emergencia.py](ex004_calculadora_reserva_emergencia.py) | Calcula quantos meses faltam para montar a reserva de emergência. | funções com `return`, `math.ceil` |
| 5 | [ex005_analise_gastos_categoria.py](ex005_analise_gastos_categoria.py) | Calcula os gastos por categoria e apresenta os maiores gastos. | dicionários, `for`, maior valor, percentual |
| 6 | [ex006_controle_habitos_semanais.py](ex006_controle_habitos_semanais.py) | Resume o aproveitamento dos hábitos semanais. | lista de dicionários, `//` e `%`, f-strings |
| 7 | [ex007_calculo_meta_financeira.py](ex007_calculo_meta_financeira.py) | Mostra em quantos meses a meta é batida, o saldo final e quanto rendeu de juros. | `while`, juros compostos, validação de entrada |
| 8 | [ex008_controle_gastos_diario.py](ex008_controle_gastos_diario.py) | Lista os gastos do dia e emite um alerta ao chegar perto do limite. | menu com `while True` + `break`, funções, `not in` |

## Como executar

Com o Python instalado, rode no terminal, dentro da pasta do repositório:

```
python ex001_orcamento_diario.py
```
